One-page newspaper front page summing up Sunday 22 November 2026 in
48 verified stories across 7 regions, drawn flat with Pillow. A
deterministic program writes a single 1024×1024 PNG under 1 MiB.
Every story's date and source are recorded in SOURCES.md; Saturday
events are named as Saturday, and only their Sunday developments are
claimed for the 22nd.

## Run it

```sh
python3 draw.py
MAKEFUN_OUTPUT_DIR=out node main.ts
```
